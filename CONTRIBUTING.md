# Contributing Guidelines

Welcome to the HCMF Software Development repository.

Please follow these guidelines when contributing:

## 1. Work in Your Assigned Folder
Only make changes inside your own folder. Do not edit or delete another fellow's files without permission.

## 2. Create a Branch
Before making changes, create a new branch from `main`.

Example:

```bash
git checkout -b your-name/feature-name
```

## 3. Commit Clearly
Use meaningful commit messages.

Examples:

- feat: add portfolio hero section
- style: update navigation layout
- fix: correct image path

## 4. Push Your Branch

```bash
git push origin your-branch-name
```

## 5. Open a Pull Request
Submit a Pull Request (PR) for review before merging into `main`.

## 6. Keep Your Folder Organized
Store all your project files inside your assigned folder and keep the project structure clean.

Thank you for contributing and happy coding!
